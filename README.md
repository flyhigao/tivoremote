# TiVoRemote (电视遥控器)

专为 **TiVo Stream 4K** 及通用 Android TV / 电视机顶盒设计的轻量级手机遥控器 APP。

内置 **Wi-Fi (局域网 ADB)** 与 **蓝牙 (Bluetooth HID)** 双通信模式，纯原生 Java 开发，体积仅约 35 KB，界面简洁无广告，支持换台必备的完整 0-9 数字小键盘与手机键盘直接打字推送功能。

---

## ✨ 功能特性

- **双通信模式无缝切换**：
  - **Wi-Fi 局域网模式（强烈推荐）**：自动或手动指定电视 IP（如 `192.168.2.223:5555`），免蓝牙配对，开机即控，毫秒级零延迟。
  - **蓝牙 HID 模式**：基于 Android 官方 `BluetoothHidDevice` API，将手机模拟为实体蓝牙键盘/遥控器（受手机厂商系统限制，见下方说明）。
- **全功能遥控按键**：
  - **D-Pad 导航盘**：上、下、左、右、居中 OK 确认（准确映射为 `KEYCODE_DPAD_CENTER (23)`，完美支持在电视软键盘上选字点击）。
  - **系统常用控制**：主页 (Home)、返回 (Back)、菜单 (Menu)、音量增加 / 减小。
  - **经典 3x4 数字小键盘**：1 ~ 9、0、删除键，专为电视家、IPTV、影视换台设计。
  - **⌨️ 手机键盘直接打字推送**：遇到电视搜索框不用再繁琐地挪方向键，在手机上打字一键直接送达电视输入框！
  - **TiVo 专属键**：支持一键唤起 TiVo Stream 官方主界面。
- **触感反馈**：每个按键操作均配有清脆的微弱触感震动反馈（Haptic Feedback）。
- **极致纯净**：无第三方 SDK、无任何商业广告、无后台自启驻留，安装包仅 ~35 KB。

## ⚠️ 重点说明：蓝牙 HID 模式在各手机系统中的兼容性限制

Android 官方在 Android 9 引入了 `BluetoothHidDevice` API，允许手机反向模拟成蓝牙键盘/遥控器（HID 外设）。但在实际使用中，**受各手机品牌系统的安全策略限制极大**：

### 1. 无法生效 / 严重受限的系统（国内主流深度定制系统）
- **OPPO / 一加 (ColorOS 13 / 14 / 15+)**
- **小米 / Redmi (MIUI 14 / HyperOS)**
- **vivo / iQOO (OriginOS 3 / 4 / 5+)**
- **华为 / 荣耀 (HarmonyOS / MagicOS)**

**为什么会受限？**  
国内厂商出于**防木马与安全合规限制**（防止手机被黑客恶意软件利用，在后台隔空伪装成蓝牙键盘向附近的电脑/电视注入恶意按键脚本，即所谓的“BadBT / 蓝牙橡皮鸭攻击”），**在系统底层阉割或拦截了普通第三方应用对外广播 HID 遥控外设通道的权限**。  
**具体表现**：电视能搜到你的手机，两端甚至能弹出并比对 6 位数字配对码；但完成配对后，手机系统拒绝开放 HID 遥控通道，电视无法将其识别为“遥控器外设”，导致电视一直停留在“连接中/正在搜索”，电视的已配对设备里只能将其识别为“普通音频/网络共享设备（PAN）”，按键完全无响应。

### 2. 可以正常生效的系统
- **原生 Android / AOSP 系统**（如 Google Pixel 系列）
- **第三方类原生开源 ROM**（如 LineageOS、PixelExperience、crDroid 等）
- 早期原生 Android 9 ~ 11 手机

> 💡 **建议**：
> - 如果你的手机是国内主流品牌，**强烈推荐使用下方的【Wi-Fi 局域网模式】**。它完全不受手机品牌系统的私有蓝牙限制，局域网直连电视底层输入通道，延迟仅 1~3ms，体验甚至优于蓝牙！
> - 若需要物理实体遥控器，在电商平台购买一个 15~20 元的**通用安卓电视蓝牙遥控器（带数字键）**（如 G10S 蓝牙版），即连即用。

## 📖 Wi-Fi 局域网模式使用指南（电视如何开启 USB 调试）

Wi-Fi 局域网模式通过网络连接电视的 ADB 端口（默认 5555）直接发送硬件级按键，**无需蓝牙配对，开机即连，全按键 100% 生效**。

使用该模式前，需要在电视上开启**“开发者选项”**与**“USB 调试”**：

### 步骤 1：在电视上开启“开发者模式”
1. 打开电视盒子，进入系统【设置】（Settings，屏幕右上角齿轮图标）。
2. 进入【设备偏好设置】（Device Preferences）->【关于】（About）（部分系统直接在设置首层的【关于】中）。
3. 找到【Android TV OS 内部版本号】或【内部版本号】（Build）。
4. **对着【内部版本号】连续快速按遥控器 OK 确认键 7 次**，直到屏幕底部弹出提示：**“您现在处于开发者模式！”**（You are now a developer!）。

### 步骤 2：开启【USB 调试】
1. 返回上一级菜单，此时会发现多出了一项**【开发者选项】**（Developer options）。
2. 点击进入【开发者选项】，向下滚动找到【调试】分类下的**【USB 调试】（USB debugging）**。
3. 将【USB 调试】开关切换为**开启（ON）**，弹窗询问时选择【确定】。
*(注：对于电视盒子，开启 USB 调试后系统默认会监听网络 5555 端口)*

### 步骤 3：获取电视的局域网 IP 地址
1. 进入电视【设置】->【网络和互联网】（Network & Internet）。
2. 点击你当前连接的 Wi-Fi 名称，查看电视的 IPv4 地址（例如：`192.168.2.223`）。

### 步骤 4：手机 App 连接电视并授权
1. 确保手机与电视连接在同一个路由器 Wi-Fi 下。
2. 打开手机上的 **TiVo 电视遥控器** App，顶部选中 **【Wi-Fi 局域网】**。
3. 点击状态栏右侧的 **【设置IP】**，输入电视的 IP 地址并确认。
4. **关键一步（仅首次需要）**：
   此时电视屏幕上会弹出一个系统对话框：**“是否允许 USB 调试？”**。
   使用遥控器勾选 **【一律允许来自这台计算机的调试】**，然后点击 **【确定】**。
5. 手机 App 状态栏绿灯亮起，显示 **`已连接 (Wi-Fi): 192.168.x.x`**，此时所有方向键、数字键、打字推送功能即可永久畅通使用！

## 🛠️ 构建与编译

本项目支持两种编译方式：

### 方式 1：独立脚本编译（无需 Gradle / Android Studio）
确保本地安装有 Android SDK（平台版本 28+）和 JDK 17+：
```bash
bash build.sh
```
执行完毕后将在根目录下生成已签名的 `TiVoRemote.apk`。

### 方式 2：Android Studio / Gradle
直接用 Android Studio 打开本目录，点击 `Build -> Build APK(s)` 即可。
